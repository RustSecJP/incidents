# RUSTSEC-2026-0190: `anyhow` の `Error::downcast_mut()` が unsound

| | |
|---|---|
| crate | [`anyhow`](https://crates.io/crates/anyhow) |
| 種類 | unsound（借用の規則に違反し、未定義動作になる） |
| 助言の日付 | 2026-06-25 |
| 影響を受ける版 | 1.0.103 より前 |
| 直った版 | `1.0.103` 以上 |
| 影響を受ける関数 | `anyhow::Error::downcast_mut` |
| 別の番号 | なし |
| 原文 | [RUSTSEC-2026-0190](https://rustsec.org/advisories/RUSTSEC-2026-0190.html)（CC0-1.0） |

## 要約

`Error::context` で文脈を足したエラーに対して、あとから `Error::downcast_mut` を呼ぶと、借用の規則に違反し、未定義動作になります。`downcast_mut` を使っていなければ当たりません。

## 自分が影響を受けたかの確かめ方

```shell
cargo tree -i anyhow --depth 0
```

1.0.103 より前の版で、自分のコードか依存先で `.context(...)` を付けたエラーに `downcast_mut` を呼んでいる場合は、影響を受けます。

```shell
grep -rn "downcast_mut" src/
```

## 直し方

```shell
cargo update -p anyhow
```

1.0.103 以上になったことを確かめます。

## 原文の訳

影響を受ける版のこの crate は、利用者が `Error::context` でエラーに文脈を足し、あとで戻ってきた `Error` に `Error::downcast_mut` を呼んだとき、借用の規則に違反し、未定義動作になります。

この欠陥は、コミット `6e8c000` で直りました。可変参照の作り方を見直し、できあがる借用の連なりに共有参照が入らないようにしています。

### 例

```rust
use anyhow::Error;
use std::fmt;

#[derive(Debug)]
struct ErrorContext(&'static str);

impl fmt::Display for ErrorContext {
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        fmt::Display::fmt(&self.0, f)
    }
}

fn main() {
    let mut error = Error::msg("inner error").context(ErrorContext("old context"));
    let context: &mut ErrorContext = error.downcast_mut().unwrap();
    context.0 = "new context";
    println!("{:?}", error);
}
```

### Miri の出力

Miri で上の例を動かすと、共有参照（SharedReadOnly）の権限しかない場所から、可変参照（Unique）を作ろうとしたとして、未定義動作が検出されます。出力の全文は[原文](https://rustsec.org/advisories/RUSTSEC-2026-0190.html)にあります。
