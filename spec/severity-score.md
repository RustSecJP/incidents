# RSJP Score: Rust 専用の重要度の採点方式（草案 0.1）

> **注意**: これは試案です。実際のキャンペーン記録が 10 件ほどたまった段階で、実例に合わせて作り直します。それまでは、記録に点数を付けません。区分と重みは仮の値で、既存の助言に当てはめて確かめながら直します。0.x の間は点数が変わることがあります。

すぐ試したい場合は[計算ツール](../calculator.md)を使ってください。

## 1. 目的

CVSS は、攻撃者が直接突ける欠陥を想定した点数です。Rust でよく問題になる次の 2 つは、うまく表せません。

- **unsoundness**（安全な Rust だけで未定義動作が起きる欠陥）: 危なさが「呼び出し方」で大きく変わる
- **悪意のある crate**: ほとんどが最高点になり、事件どうしの差が付かない

RSJP Score は、Rust に固有の事情（安全な Rust だけで踏めるか、ビルド時に発火するか、どれだけ依存されているか）を軸にして、0.0〜10.0 の点数を出します。

RSJP Score は RustSecJP の見解です。RustSec や CVSS の評価を置き換えるものではありません。

## 2. 出し方

点数と、内訳を表す文字列を必ず組で出します。文字列があれば、誰でも点数を計算し直せます。

```
RSJP Score 9.5
RSJP-S:0.1/K:M/I:X/T:B/U:N/S:Y/A:X/R:W/E:X/F:R
```

## 3. 軸と値

### 影響

| 軸 | 値 | 意味 | 重み |
|---|---|---|---|
| **K** 種類 | `M` | 悪意のあるコード | — |
| | `U` | unsoundness | — |
| | `V` | 通常の脆弱性 | — |
| **I** 起きること | `X` | 任意のコード実行 | 1.00 |
| | `S` | 秘密（鍵・トークン・ソース）の窃取 | 0.95 |
| | `M` | メモリ破壊（未定義動作） | 0.90 |
| | `L` | 情報漏れ | 0.60 |
| | `D` | 停止（パニック、無限ループ、資源の枯渇） | 0.50 |

K は分類のための軸で、点数には掛けません。

### 踏まれやすさ

| 軸 | 値 | 意味 | 重み |
|---|---|---|---|
| **T** 発火の時点 | `B` | ビルド時（`build.rs`、proc-macro）。依存に入れるだけで動く | 1.00 |
| | `L` | 起動時・読み込み時 | 0.95 |
| | `C` | 特定の API を呼んだとき | 0.85 |
| **U** 踏みやすさ | `N` | 普通の使い方で踏む | 1.00 |
| | `U` | 珍しい使い方で踏む | 0.60 |
| | `C` | わざとらしい使い方でしか踏まない（特殊な trait 実装を自作する など） | 0.30 |
| **S** 安全な Rust だけで踏めるか | `Y` | 踏める | 1.00 |
| | `N` | `unsafe` の契約違反が要る | 0.50 |
| **A** 信頼できない入力 | `R` | 外部からの入力で届く | 1.00 |
| | `C` | 呼び出し側のコードしだい | 0.70 |
| | `N` | 届かない（書き手の誤用でのみ起きる） | 0.40 |
| | `X` | 当てはまらない（悪意のあるコードなど、入力が要らない） | 1.00 |

### 補正

| 軸 | 値 | 意味 | 重み |
|---|---|---|---|
| **R** 影響の広さ | `W` | とても広い | 1.00 |
| | `H` | 広い | 0.90 |
| | `M` | 中くらい | 0.80 |
| | `L` | 狭い | 0.70 |
| | `N` | ほぼ使われていない | 0.60 |
| **E** 確かさ | `X` | 実際の悪用を確認 | 1.00 |
| | `P` | 再現できる（再現コード、Miri などで確認） | 0.95 |
| | `T` | 理論上のみ | 0.80 |
| **F** 修正の状況 | `N` | 修正なし | 1.00 |
| | `R` | crate ごと削除、または該当版を取り下げ済み | 0.95 |
| | `F` | 修正版あり | 0.90 |

R の区切り（その crate に依存する crate の数、ダウンロード数のどこで線を引くか）は、0.1 では未確定です。既存の助言に当てはめてから決めます。

## 4. 計算

```
踏まれやすさ = T × U × S × A
基礎点       = 10 × I × 踏まれやすさ
RSJP Score   = 基礎点 × R × E × F   （小数第 2 位を切り上げ、小数第 1 位まで）
```

### 段階の呼び名

| 点数 | 呼び名 |
|---|---|
| 9.0〜10.0 | 緊急 |
| 7.0〜8.9 | 高 |
| 4.0〜6.9 | 中 |
| 0.1〜3.9 | 低 |

## 5. 計算の例（架空の事例）

実在の助言への採点ではありません。式の動きを見るための例です。

| 例 | 文字列 | 計算 | 点数 |
|---|---|---|---|
| 広く使われる crate が乗っ取られ、ビルド時にコードを実行。悪用を確認、版は取り下げ済み | `K:M/I:X/T:B/U:N/S:Y/A:X/R:W/E:X/F:R` | 10 × 1.00 × 1.00 × 1.00 × 1.00 × 0.95 | 9.5 |
| ほぼ使われていない偽装 crate。中身は上と同じ | `K:M/I:X/T:B/U:N/S:Y/A:X/R:N/E:X/F:R` | 10 × 1.00 × 1.00 × 0.60 × 1.00 × 0.95 | 5.7 |
| 広く使われる crate の unsoundness。普通の使い方と外部入力で届く。再現あり、修正版あり | `K:U/I:M/T:C/U:N/S:Y/A:R/R:W/E:P/F:F` | 10 × 0.90 × 0.85 × 1.00 × 0.95 × 0.90 | 6.6 |
| わざとらしい使い方でしか踏まない unsoundness。中くらいの広さ、再現あり、修正版あり | `K:U/I:M/T:C/U:C/S:Y/A:C/R:M/E:P/F:F` | 10 × 0.90 × (0.85 × 0.30 × 0.70) × 0.80 × 0.95 × 0.90 | 1.1 |

## 6. 採点の決まり

- 採点には根拠を添えます。軸ごとに「なぜその値か」を 1 行で書きます。
- 分からない軸は、勝手に高くも低くもしません。「不明」と書き、点数は出しません。
- 新しい事実が出たら採点し直し、履歴を残します。

## 7. これから決めること

- R の区切りの数字
- 重みの見直し（既存の助言 30 件ほどに当てはめて、直感とずれないか確かめる）
- 掛け算だけの式でよいか（低い値が重なると点数が下がりすぎないか）
- 計算ツール（文字列を入れると点数が出るもの）
